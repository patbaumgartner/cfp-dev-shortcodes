# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| Latest release | Yes |
| Earlier releases | No |

## Reporting a Vulnerability

Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/patbaumgartner/cfp-dev-shortcodes/security/advisories/new) for `patbaumgartner/cfp-dev-shortcodes`. Do not disclose the vulnerability in a public issue, pull request, or discussion until a fix is available.

We aim to acknowledge reports within five business days and will keep you informed about validation, remediation, and coordinated disclosure.

## Scope

This policy covers this WordPress plugin only. It does not cover the upstream CFP.DEV API, CFP.DEV-hosted instances, or other third-party services used by the plugin.
